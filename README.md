# LLM Parkinsonism Solutions

Research by Dongsheng Xiao on task-level executive control in language-model agents.

This repository contains an academic manuscript, provider-neutral control architecture, deterministic artifact integration, and reproducible experiments. The research distinguishes verified completion from premature stopping and examines whether self-created architectural obligations should be repaired or removed while preserving the original task contract.

Implementation, data, and full documentation are being assembled in the next commit. Experiments performed in this project are explicitly identified as synthetic or scripted; no GPT-6 evaluation or measured LLM token savings is claimed.
